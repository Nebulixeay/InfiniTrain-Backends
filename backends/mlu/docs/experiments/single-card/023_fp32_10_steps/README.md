10 步之间有约 `47.79 s` 的固定未测量间隔（step 2–10 的中位数），它不改变十步完成结论，但应作为后续性能定位入口。

023 的二进制原始 hash 与 020 不同，差异来自 staging 路径和编译器临时名；`binary_vs_020.txt` 记录了归一化后逐位相同的结果，不能把它写成原始 hash 相同。

该二进制来自带未提交改动的工作树；`source_commit` 只标识运行时 HEAD，不能单独重建该二进制。
